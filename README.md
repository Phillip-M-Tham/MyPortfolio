home page that contains introduction.

## Algorithm.html
Page to host Algorithm maze solvers with a 40x60 ASCII maze hosted in maze.txt.
Uses umbrella.js to create Resident Evil red queen theme for animated background.
### Breadth First Search(BFS)
    Shows solution using BFS algorithm using an array to conduct First in First Out operations.
### Depth First Seach
    Shows solution using DFS recursively to implement Last In First Out operations. 
### Dijkstra
    Shows solution using Dijkstra's Algorithm. Created a min heap class to conduct bubble up and bubble down functions to replicate heapq priority queue operations.
